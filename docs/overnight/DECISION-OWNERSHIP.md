model decides. **Structural executor** = what code decides and enforces. **Verification status** uses
the separated vocabulary (implemented / unit-tested / integrated / live-verified) and is deliberately
not a single "done" column. Legacy or unreachable paths are listed at the bottom, not silently merged
into the live rows.

Verified by reading the current callers, not the file names in the amendment. Paths that were renamed
since the amendment was written are marked.

## Retired / legacy / unreachable (kept for honesty, not counted as production paths)
- `lib/skills/coreRouter.ts` keyword router: **removed 2026-10-18**; core skills fire only through the
  decision engine's mode->skill table.
- `ruke_ml/workers/runner.py` fixed-failure OCR/ASR dispatch stubs: replaced by the real adapters; the
  old "return a canned failure" shape is gone.
- `documents/ocr.py` legacy `ocr_status()` shim: still imported for the status surface, delegating to
  `ocr_tesseract.engine_state()`; it is **not** the execution path (the cascade is).
- The Python artifact handlers (`artifacts.xlsx/docx/pptx` capability rows): present in the registry as
  **not-migrated/retained-TS** markers, deliberately not executable; a registry row is not an adapter.
- Any path still labelled `not_configured` for neural rerank in the **capability surface**: truthful
  until `nn_embed/reranker` get a caller; the lexical baseline keeps its `lexical` label.

## What this table is NOT
It does not claim the model's choice is always right, and it does not claim the code's choice is
quality-optimal. It records who owns each decision and what evidence exists. A row whose verification
status says "HELD" is not complete, no matter how many unit tests pass around it.
